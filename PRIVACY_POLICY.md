# Политика конфиденциальности ArcheAge Extra UI

Дата вступления в силу: 4 сентября 2026 г.

ArcheAge Extra UI — неофициальное браузерное расширение для улучшения интерфейса игровых страниц ArcheAge.

## Обрабатываемые данные

Расширение обрабатывает содержимое страниц и ответы игровых API только на следующих сайтах:

- `https://archeage.ru/`
- `https://gisaa.ru/veksel/`

Эти данные используются исключительно на устройстве пользователя для работы функций расширения: отображения расписания и таймеров, улучшения Марафона героев, корзины, восстановления предметов и таблиц векселей.

Расширение может сохранять в локальном хранилище браузера технический кэш и пользовательские настройки, необходимые для его работы. Например, локально может храниться история выполненных заданий.

## Передача и использование данных

Расширение не передаёт, не продаёт и не предоставляет пользовательские данные разработчику или третьим лицам. Оно не получает отдельный доступ к паролям, платёжным данным, личным сообщениям, геолокации или истории посещений сайтов.

Для работы на указанных сайтах расширение обращается к игровым страницам и API в рамках текущей сессии пользователя. Оно также может загружать общедоступные изображения предметов с `archeagecodex.com` и статические изображения с CDN игры.

Пользовательские данные не используются для рекламы, профилирования, определения платёжеспособности или кредитования.

## Изменения политики

При изменении способов обработки данных эта политика будет обновлена до выпуска соответствующей версии расширения.
