# ArcheAge Extra UI

Неофициальное расширение для улучшения интерфейса ArcheAge на [archeage.ru](https://archeage.ru/) и [gisaa.ru](https://gisaa.ru/veksel/).

## Возможности

- Марафон героев: расписание, игровые и московские часы, таймеры, прогресс, история выполненных заданий и быстрый переход между днями.
- Корзина и восстановление предметов: поиск, сортировка, фильтры, подсказки и наглядный список выбранных предметов.
- Таблицы векселей на gisaa.ru: ссылки на нужные таблицы и подсветка подходящих строк.
- Кнопка быстрого перехода к марафону с недельным прогрессом.

Расширение работает только на `archeage.ru` и `gisaa.ru/veksel`.

## Установка

### Firefox

После публикации установите дополнение со страницы Firefox Add-ons. Для локальной проверки откройте `about:debugging`, выберите **Этот Firefox**, нажмите **Загрузить временное дополнение** и укажите `dist/firefox/manifest.json`.

Для работы Firefox-версии требуется Firefox 128 или новее.

### Chrome

Соберите каталог расширения командой:

```powershell
npm run build:chrome
```

Загрузите папку dist/chrome через страницу расширений Chrome в режиме разработчика. Импортированные PNG размещаются отдельно в dist/chrome/assets.

Для разработки запустите Chrome for Testing с расширением и наблюдением за исходниками:

```powershell
npm start
```

На Windows повторный запуск перезапускает Chrome с профилем `.chromeDevProfile`, чтобы загрузить актуальный manifest. Авторизация в этом профиле сохраняется. После изменения исходников обновите расширение на `chrome://extensions` и затем вкладку сайта.

Для проверки запуска в настоящем браузере выполните `npm start -- --check`. Команда проверяет загрузку скриптов и наличие видимой `.tm-side-panel` на главной странице, сохраняет снимок панели в `.test/start-check.png` и закрывает тестовое окно. При ошибке проверка завершается с ненулевым кодом.

## Сборка Firefox XPI для AMO

Требования:

- Node.js 20 LTS с npm;

На Windows, macOS или Linux в корне проекта выполните:

```powershell
npm ci
npm run build:firefox:xpi
```

Итоговый пакет появится в корне проекта: `archeage-extra-ui-firefox.xpi`.

Сборка использует esbuild для преобразования каждого TypeScript-файла в отдельный минифицированный JavaScript-модуль, а Sass — для компиляции отдельных минифицированных CSS-файлов. Минификация включена во всех режимах сборки, включая `npm start`. Firefox-версия содержит скрипт в контексте страницы для перехвата API и изолированный content script для интерфейса расширения.

### Архив исходников для AMO

Чтобы подготовить архив с исходным кодом без зависимостей и готовых артефактов, выполните:

```powershell
npm run package:firefox:source
```

Команда создаст `archeage-extra-ui-source.zip`. В нём находятся исходники, скрипты сборки, `package-lock.json`, политика приватности и лицензия.


## Структура проекта

| Путь | Назначение |
| --- | --- |
| `src/` | TypeScript-код, стили и локальные ресурсы расширения |
| `src/adapter/` | Адаптер расширения и мост к API страницы |
| `src/extension/contentScript.js` | Загрузчик модуля текущей страницы |
| `src/pages/` | Логика и стили страниц; `index.ts` запускает соответствующую страницу |
| `src/components/`, `src/utils/`, `src/data/` | Переиспользуемые компоненты, функции и данные |
| `scripts/` | Сборка Firefox-версии и упаковка XPI/исходников |
| `build.js` | Конфигурация сборки esbuild и Sass |
| `PRIVACY_POLICY.md` | Политика приватности |

В `dist/chrome/modules/` и `dist/firefox/modules/` сохраняется структура исходников: каждый `.ts` превращается в `.js`, а `.scss` — в соседний `.css`. Например, `pages/cart/index.js`, `pages/cart/cart.js` и `pages/cart/cart.css` остаются отдельными файлами. Изображения лежат в `assets/` и загружаются по URL расширения.

Загрузчик импортирует `pages/<страница>/index.js` для текущего адреса. Его зависимости подключаются обычными `import`; общий модуль загружается и выполняется один раз в рамках документа. CSS подключается через manifest согласно зависимостям страницы. Дополнительных действий от пользователя после установки расширения не требуется.

## Приватность

Расширение обрабатывает содержимое страниц и ответы игровых API только локально в браузере. Оно не отправляет, не продаёт и не передаёт пользовательские данные разработчику или третьим лицам. Технический кэш и пользовательские настройки могут храниться в локальном хранилище браузера.

Подробности — в [политике приватности](PRIVACY_POLICY.md).
